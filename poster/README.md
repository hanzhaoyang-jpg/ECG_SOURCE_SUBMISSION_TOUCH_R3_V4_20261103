定位：用于项目展示、答辩预热与中文交流。AMD 赛题指南要求进入自主选题决赛的队伍使用其模板制作一页英文 PPT 海报；本稿不替代该正式提交物。

## 文案边界

- 板卡：正点原子领航者 Zynq-7020；采集链路为 CN121 + AD9280，设计采样率 360 Hz。
- 板端包含滤波、信号质量评估、R 峰与 HR/RR、既有 HLS CNN 推理、LCD 与 SD 记录；联网版使用有线 UDP 传输至工作站。
- CNN 标签为 N/S/V/F，不给出没有实测依据的准确率、加速比、延迟或零丢样结论。
- 触摸 r3 仅有用户反馈的 JTAG 实机观察；完整构建、SD 冷启动和真机网络联调仍待验收。海报以“系统设计/功能链路”表述，不把这些状态称为已完成验收。
- 不是医疗诊断设备，不宣称疾病诊断或临床适用。

## 建议补充的决赛证据

板卡与采集实物照、真实 LCD 与工作站截图、板上测试记录、CNN 与软件基线的性能/资源对比、综合实现与时序报告、从零构建记录。取得实测数据后再加入量化数字。
