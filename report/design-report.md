# Zynq-7020 长时 ECG 监测系统

全国大学生嵌入式芯片与系统设计竞赛 AMD 自主选题赛道高级组

## 设计目标

系统在板端完成 ECG 采样、显示和存储，离线模式可独立运行。联网模式通过有线 UDP 向工作站发送波形与分类事件。系统面向工程验证，板端测试使用固定输入或 ECG 模拟器。

## 数据链路

```text
CN121 → AD9280 → PL 采集与 FIFO → PS 滤波、SQI 与 R 峰检测
                                   ├─ AXI DMA → PL CNN → PS 分类结果
                                   ├─ LCD 与触摸交互
                                   ├─ SD 采样与事件记录
                                   └─ 有线 UDP → Go 工作站
```

PL 负责定时采集和 CNN 运算。PS 负责滤波、信号质量判定、心拍组织、记录和界面控制。采样率为 360 Hz。SQI 为 GOOD 且 CN121 就绪时才运行 R 峰检测。联网协议为 UDP v1，端口 5005，每包 28 字节。

## 采样与记录设计

ADC 时钟和记录速率独立。默认 ADC 时钟为 10 MHz，PL 用相位累加产生平均 360 Hz 的记录节拍，PS 通过 AXI-Lite 读取 FIFO。样本 CSV 保留原始 ADC、两路滤波输出、QRS 包络及 SQI 状态，事件以记录内样本编号与波形对齐。低量程余量单独预警，削顶等坏信号才触发相应门控。运行时检查累计采样数、读取量和 FIFO 存量，并分别统计显示、存储和推理耗时。

## 离线运行与工作站

两版共用板端 C 源码。离线版通过 LCD、触摸和 SD 卡完成本地操作。联网版通过板载 PS 网口发送 UDP，开发板和电脑可直接用网线连接。默认板端地址为 192.168.7.10/24，电脑设为 192.168.7.1/24。工作站收到数据后进入「实时 · UDP」，收包计数持续增加；断流会在界面提示。电脑保存的是收到的数据副本，板端 SD 记录独立运行。工作站的 R 峰和 HR/RR 由浏览器根据接收波形估计，验证板端算法时使用 SD 事件。

## 触摸驱动修复

板端曾显示 `NO ACK AT 0X38`。排查保留 FT5206/FT5426 的 7 位地址 0x38，转而检查 GPIO 能否拉低 SDA 和 SCL。r3 在切换 GPIO 为输出后明确清零数据锁存位，并在 I²C START 时检查线路是否实际拉低。诊断 ELF 经 JTAG 运行后，用户观察到 `TAP TOP LEFT`，完成校准后六个按钮均可点击。这个结果对应诊断 ELF 的上板测试。V4 合入了修复源码，并重新生成了 SD 启动镜像，正式镜像的触摸冷启动验收待补。

## 构建与实现结果

目标器件为 xc7z020clg400-2。V4 保留工程已验证的 Vivado 和 Xilinx SDK 2018.3，构建命令见 [README](../README.md)。2026 年 11 月 3 日从独立解压目录执行了 BD 生成、综合、布局布线和比特流导出，并用新生成的 HDF 构建 FSBL。离线和联网版 BOOT.BIN 均由 Bootgen 2018.3 生成。

## 板端验证

团队已完成一次连接外设的整机上电。待补验证包括固定 ECG 输入下的 R 峰与参考位置对照、SQI 状态、SD 记录连续性和联网数据接收。当前没有足够数据填写检测准确率、长测结果或性能基线对比。两版启动文件均已生成，打包脚本在验收清单阶段因缺少测试日志停止。
