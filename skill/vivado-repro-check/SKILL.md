---
name: vivado-repro-check
description: 从独立副本构建 Vivado 工程，核对源码和 IP 路径、构建阶段、时序报告以及输出来源。
---

1. 将提交包解压到新目录，使用包内脚本和指定版本的 Vivado。将输出写入新目录。记录项目路径、工具版本和目标器件。
2. 核对 Vivado 日志中的工程路径、IP 仓库、综合源文件、XDC 和内存初始化文件。将路径统一大小写和分隔符后，再按目录边界区分解压副本与旧工作区。工具自带 IP 应归到工具链路径。
3. 检查构建退出状态，区分 BD/IP 生成、综合、布局布线和比特流导出。确认输出来自本次运行。读取布线报告中的 WNS、WHS、失败端点和资源用量，记录 DRC 结果。
4. 需要生成 SD 启动包时，用本次导出的 HDF 构建 FSBL，核对 BIF 中的 FSBL、比特流和应用 ELF。分别记录镜像生成、验收清单生成、上板冷启动三个结果。

这个流程来自两次实际排查。第一次日志还在综合，无法据此确认比特流生成。第二次 Bootgen 已写出镜像，随后验收清单因缺测试日志停止。复用时以实际日志和文件为准。若必须证明没有日志之外的访问，使用隔离环境或文件访问追踪。
