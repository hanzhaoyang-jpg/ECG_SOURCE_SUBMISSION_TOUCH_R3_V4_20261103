ECG R峰标注与逻辑训练工具

目标：加载 SD 卡导出的 RECxxxx.CSV，人工标注真实 R 峰，用当前板端滤波/SQI/R峰/RR逻辑复现检测结果，然后用标签评估与搜索参数。页面为纯前端，数据不会上传。
显示辅助
SQI 区间标签 SQI labels: 0
操作：鼠标左键点击波形附近添加/删除人工 R 峰；按住 Shift 点击可强制添加；滚轮缩放，A/D 或 ←/→ 前后移动。点击时会自动吸附到附近最大绝对幅值点。SQI 用“当前显示窗口”做区间标签：GOOD 表示适合检测，CLIPPED 表示 ADC 贴近 0/255 或卡死，NOISY 表示运动噪声/毛刺，DRIFT 表示基线漂移，FLAT 表示平线/接触异常。带“实时候选”的通道都是逐点因果滤波，不使用未来数据，只用于先比较显示效果。
